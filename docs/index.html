ABOUT THIS SPACE

你的知识工作台

数据保存在当前浏览器

这个模板从空白知识库开始。收藏、精选和自定义领域保存在 localStorage。换浏览器、换设备或清除浏览器数据时，请先导出 JSON 备份，再在目标浏览器导入。

如何扩展分类？

点击侧栏“新建领域”，填写名称并选色。收藏时选择领域；标签可补充“论文、课程、项目”等交叉维度。

链接整理

当前版本保存你填写的链接和笔记。可以复制整理指令交给助手阅读。可在“AI 设置”接入自己的兼容 API，分析粘贴的文字。网站尚未接入自动抓取或云端同步服务。

设计参考

参考 Quartz 的知识网络组织方式和 Kaiforge Lite 的仪表盘结构。界面独立实现。

新建知识领域

例如：强化学习、机器人感知、产品设计。新领域可用于分类、搜索和知识图谱。

领域保存在当前浏览器，也会包含在 JSON 备份中。更多交叉维度可在收藏时填写标签，例如“待读论文、课程、项目”。

AI 设置

支持 Chat Completions 兼容 API。填写厂商文档中的完整请求地址和模型 ID。服务必须允许浏览器跨域请求（CORS）。

文字和密钥会直接发送到你填写的服务。密钥不会写入备份或 GitHub。使用可信的服务地址；测试与分析可能产生 API 费用。无密钥的自建网关可留空。

本机加密保存（可选）

首次填写 API Key 后，设置至少 12 个字符的解锁口令。刷新后输入口令，即可恢复密钥。口令不保存，忘记后需重新填写 API Key。此功能不随 Google 账户同步。

分析这条收藏

分析单独保存到这条收藏，不覆盖笔记。结果随 JSON 备份导出。模型输出需要核对。
